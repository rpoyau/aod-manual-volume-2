\paragraph{Setup.}
Each record identifies its data support before its report coordinate. D0 denotes
an exact internal fixture comparison; O0 denotes a declared observable-map
comparison. A dash means that this row is a reference, source or acquisition
record rather than such a comparison. Record form, model premises and execution
evidence retain the separate meanings of \secref{manual2:data-support}. The
registry locates calculations and sources; it is not an agreement verdict.
The application roles below are descriptive. Normative record forms and claim
classes are bound component by component in
\path{manual2/data/m1/classification/data_cards.json}.

\paragraph{Specialization.}
The original v94 observable matrix has 708 rows: 118 E0 identity/registry rows,
and 118 rows in each of E1 placement/classification, E2 atomic mass/standard
atomic weight, E3 isotope support, E4 spectra and E5 reaction/routes. E0 is the
active historical registry; E1--E5 are unscored declarations. Its ten value maps
were not attached. That historical scope is separate from the six-field
placement comparison, and the exact predecessor status tokens remain in the
source crosswalk.

The r24 crosswalk retains occurrence, transition-packet and SADAR declaration
IDs as historical identifiers. These declarations contain no executed
source-to-destination event witnesses or measured scores. Correspondence of
the original and public atlas is bound by parsed manifest content and five
matching file hashes; it is not an identity claim about an entire public
repository.

\paragraph{Falsification.}
A target record without its value map and compatible coordinate cannot acquire
a residual. A source hash cannot supply a construction witness. A historical
declaration cannot substitute for an executed transition. These distinctions
apply independently of the D0 or O0 support code.

\paragraph{Provenance.}
The release provenance records the reviewed PR, original v94/r24 archive hashes, extracted member hashes, the six-field mapping, historical identifier joins and the current input bindings. Small verified source extracts and the generated \path{declaration_crosswalk.csv}, \path{observable_coverage.csv} and \path{value_map_status.csv} are stored under \path{manual2/data/m1/history/}. Their bindings are in \path{manual2/evidence/historical_sources.json}; current input hashes are in \path{manual2/evidence/input_manifest.json}. Exact static checks, source identity checks and any future scientific claims retain separate result scopes.
