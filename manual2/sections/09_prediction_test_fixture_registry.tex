\paragraph{Specialization.}
The original v94 observable matrix has 708 rows: 118 E0 identity/registry rows marked \texttt{active\_registry}, and 118 rows in each of E1 placement/classification, E2 atomic mass/standard atomic weight, E3 isotope support, E4 spectra and E5 reaction/routes marked \texttt{declared\_lane\_not\_scored\_in\_v94}. Its ten value maps remain \texttt{deferred\_not\_attached}. These statuses are separate from the successful six-field placement comparison.

The r24 crosswalk retains occurrence, transition-packet and SADAR declaration IDs as historical IDs. Its execution remains declared but unexecuted; target values are not read, measured reports are closed and scores absent. It does not contain source-to-destination event witnesses. Correspondence of the original and public atlas is bound by parsed manifest content and five matching file hashes; it is not an identity claim about an entire public repository.

\paragraph{Falsification.}
A historical pending lane promoted to a current execution result without new evidence, or a hash comparison described as scientific admission, violates the inventory. Preserve predecessor status and current status in distinct fields. Prerecorded counterfactual outcomes do not count as actual hostile tests.

\paragraph{Provenance.}
The release provenance records the reviewed PR, original v94/r24 archive hashes, extracted member hashes, the six-field mapping, historical identifier joins and the current input bindings. Small verified source extracts and the generated \path{declaration_crosswalk.csv}, \path{observable_coverage.csv} and \path{value_map_status.csv} are stored under \path{manual2/data/m1/history/}. Their bindings are in \path{manual2/evidence/historical_sources.json}; current input hashes are in \path{manual2/evidence/input_manifest.json}. Exact static checks, source identity checks and any future scientific claims retain separate result scopes.
