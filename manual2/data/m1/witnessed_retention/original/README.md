# Witnessed cancellation and retention — R03

The cancellation test now has admitted return, coupling and outer-retention
witnesses. **Nonnegative burden is consumed by the next retention kernel in
this fixture.** It is no longer only a diagnostic column. This is a selected,
exact finite model; it does not establish an isotope-specific loss law.

## Question and fixed inputs

The test asks whether opposite oriented responses can cancel signed memory
without erasing carried burden, and whether that distinction changes the next
retention decision under the same declared weight formula.

The scientific sources are pinned to AOD
`3ffb3c9984eef95ca4b105ac323d249f30412816` and Matter I
`192cad032cdf579344ab21aa25a0bf7454981e89`. Both PR heads were refreshed at task
entry and still matched these commits. The source admission implementation and
the historical survival implementation are preserved unchanged. The attached
owner plan supplies the causal-update and lineage-preservation requirements.

The candidate uses the existing plus/minus Q4 square routes; the reference
uses the reference square. Every executed traversal is Hamming-1, and each
completed return has its own certificate. A recurring `3:4:6` background is
constructed from its ordered word/shell occurrences and component witnesses.
Its support has 68 outward occurrences and RD `68 + 1 + 68 = 137`, obtained
from the actual construction, not a hardcoded pressure.

Preparation contains four candidate returns, two reference returns and three
background returns. These are explicit fixture choices. After the next
reference return, the committed candidate/reference bip difference is one.
When the background also completes its next return, candidate/background lag
is zero. Phase bias is zero. Thus lag is obtained from certified return counts;
it is not assigned from the `+` or `-` response symbol. Changing the preparation
to three candidate returns makes the first reference lag zero in a control.

The outer parent folds the evolving candidate wave and has two formation
returns. Reference and background remain external fields. Measurements count
new returns after parent formation and stop at the third new reference return.
The preparation history is preserved separately. This is a controlled return
protocol, not a free-running simulation of nuclear internal motion.

## Operator chain and normalization

Each round executes the reference return and its bound cross-return, then the
background return and its cross-return. A pending-background intervention
commits only the first H1 edge of its second new return. No completed background
closure is fabricated. Interrogation contacts continue to bind its existing
recurring prefix and pending state.

Repeated contacts supply directional RCD. Actual forward and reverse support
traces are retained, including any additional reflection count. Their
participation uses the frozen compatible integer count window. `C3=1` per
declared channel. On an accepted candidate return, orientation is taken from
that return's witness. The committed response adds

\[
R\;\leftarrow\;R+\sum_j \rho_j\Lambda_j i,
\qquad
B\;\leftarrow\;B+\sum_j \rho_j|\Lambda_j|.
\]

Each contribution binds the actual comparison cut, both prefixes, contact IDs,
lag, pressure, direction, and candidate return. Validation regenerates these
operands from the committed records. Drift is the difference from the previous
bound comparison, rather than repeatedly taking zero as the prior lag.

The reference cross-return has structural RD **5**. The declared diagnostic
unit is therefore `u=5` raw count-domain units. The diagnostic capacity `C=1`
means **raw closure capacity 5**, not raw capacity 1. Both signed response and
burden use the same normalization, fixed before execution.

For selected raw load `L`, the unchanged diagnostic kernel formula is

\[
X=\frac{\max(0,L-5)}5,
\qquad (w_+,w_-,w_{\mathrm{exit}})=(1,1,X),
\qquad P=w/\sum w.
\]

`L=|R|` is the net-memory comparison. `L=B` is the nonnegative-burden case.
Both are explicit model selections. The current round's comparison is an
operand of the subsequent committed response; it cannot change the kernel
that precedes that response. No lifetime, fitted hazard, SI gain or experimental
target is read as an operand.

## Exact results

In the baseline each reference contribution has pressure 5 and lag 1; the
background has pressure 137 and lag 0. Consequently each accepted response
carries raw burden 5, regardless of its orientation.

| Prefix | Raw signed response | Raw burden | Diagnostic signed response | Diagnostic burden | Next exit with net memory | Next exit with burden |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `++` | 10 | 10 | 2 | 2 | 1/3 | 1/3 |
| `+-` | 0 | 10 | 0 | 2 | 0 | 1/3 |
| `-+` | 0 | 10 | 0 | 2 | 0 | 1/3 |
| `--` | −10 | 10 | −2 | 2 | 1/3 | 1/3 |

Each two-return prefix has exact probability 1/4. The first two decisions have
zero exit weight. Therefore the independently checked third-return results are

\[
S_{\mathrm{net}}(3)=\tfrac14(\tfrac23+1+1+\tfrac23)=\tfrac56,
\qquad S_{\mathrm{burden}}(3)=\tfrac23.
\]

| Frozen comparison | Retained probability after reference return 3 | Absorbed probability |
| --- | ---: | ---: |
| Net memory | 5/6 | 1/6 |
| Nonnegative burden | 2/3 | 1/3 |
| Burden input disabled after response 2 | 1 | 0 |
| Only the latest response group participates | 1 | 0 |
| Second new 3:4:6 return held pending | 5/76 | 71/76 |

The first four cases have identical committed event prefixes before the third
decision. Disabling feedback preserves the full burden history while gating
its use. Restricting the active response-group window excludes an earlier group
with an explicit disposition; it does not erase that group. The duration-
participation window remains frozen. This tests a change in active membership,
not an unexplained reduction of the burden of a fixed group.

The pending-background control changes its second measured lag from zero to
one. The second response therefore carries raw burden `5 + 137 = 142`; with
the first response its total is **147**. The same frozen rule then gives
`P_exit=(147−5)/(10+147−5)=71/76`. This deliberately strong intervention is a
finite-model causal test, not a measured isotope effect or fitted decay rate.

The separate directional control adds one reverse reflection count to each of
two contacts. Forward RCD remains 5 and reverse RCD becomes 7; directional
equality is not assumed. Complete sign reversal changes signed response while
preserving the magnitudes in this fixed-channel orientation control.

to the outer start. The computed exoshedding record binds the selected load,
capacity, preceding outer certificate, source state and contributing history.
The exposure check preserves the entire evolving candidate wave and all its

in the open exit. Initial closure, prior reclosures, H1 traversals and reference

are censored at this fixture's horizon. No daughter nucleus is inferred.
