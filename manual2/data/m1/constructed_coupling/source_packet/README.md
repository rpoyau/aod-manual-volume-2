# Matter I: constructed-field coupling and closure counts

This run advances the earlier shared-surrogate counting pilot to a concrete,
isotope-indexed finite construction. **It does not predict the number of
closures before physical Og-294 decays.** Its outer trajectory now depends on
the constructed constituent inventory and actual coupling history. The nuclear
identification, resolved internal dynamics, closure capacity and parent-loss
predicate remain unprovided.

## What ran

The selected nucleus candidate retains 118 distinct admitted `3:3:6`
constituent waves and 176 distinct admitted `3:4:6` constituent waves. Each has
two formation returns with separate lineage IDs, Hamming-1 traces, primitive
component evidence and motif witnesses. This is the external proton-facing /
neutron-facing assignment used in Matter I; it is not a derivation of protons,
neutrons or their physical assembly. Electron shells are outside this run.

A declared scope map sends each ordered constituent word/shell occurrence to
its last-axis H1 traversal in an outer Q4 register. The parent traces the full
ordered branch, one hinge and the reversed branch. The fold certificate binds
every inner wave and the scope map. Thus the branch has
`118 × 30 + 176 × 68 = 15,508` traced occurrences, and its structural RD is
`15,508 + 1 + 15,508 = 31,017`. This is a witnessed, chosen composition; it is
not a claim that every nuclear RD equals a scalar support sum. Intermediate
visits to the retained vertex do not become additional certified parent
returns.

The 294 inner formation histories remain frozen and preserved. Five outer
fields evolve: the parent `P`, a reference `R` folded from a `3:3:6` support,
and three backgrounds folded from `3:4:6` supports. `B0` and `B1` remain
bidirectionally coupled to the parent. `B2` receives parent returns from
formation; the intervention enables its return influence on the parent.
These are five evolving aggregate fields, **not 294 independently evolving
nuclear constituents**. The reference is not identified with Cs-133.

The previously declared inverse-pressure sequencer is used with the same law
in every case. Each action's next deadline is committed using its own structural
RD plus the incoming last-two-contact RCD durations. A contact arrival cannot
rewrite an already committed deadline. Each actual outer reclosure emits one
packet per outgoing channel; the receiver/sender phases at emission determine
the declared directional reflection counts. Every received packet binds both
prefixes and its returned support trace.

The full horizon was frozen at cut 4,000,000,000, with feedback intervention at
cut 1,000,000,000. These are execution coordinates, not seconds or bips. No
lifetime, isotope-specific hazard, fitted capacity, SI gain or calibration
constant is an operand of the evolution. A deterministic trajectory is run per
case, so these are neither sampled survival estimates nor a decay distribution.

admission at cut 63,037. Its two prior formation returns are excluded.

The matching final ratio hides a timing change. Added feedback delays the second,
third and fourth parent reclosures by **4,096,026**, **8,345,355** and

unchanged. Disabling the feedback restores the complete baseline trajectory,
not only the final count. All three cases have identical committed base events
before intervention. Removing one constituent changes the actual scope map,
branch, RD and trajectory; changing only the isotope label has no effect.

These results demonstrate population- and window-dependent relational cadence
**within this chosen finite model**. They do not establish a physical clock
drift, an SI mapping or a universal window law. Structural RD, contact RCD and
elapsed execution-cut separation are recorded separately. In the final baseline
P/R comparison, operative `P ← R` RCD is 61, while `R ← P` RCD is 34,292.
Their asymmetry is retained. Added feedback changes the latter to 34,301 while
the final count ratio is unchanged.

The baseline has 11,212 directed tick emissions and 11,212 returned clicks, with
no current in transit at the horizon. Each returned channel trace has a bound
Dion–Monon-pivot–Dion motif witness. Repeated returns admit a Duon current. The
seating check keeps that same current identity as a Duad state, under explicitly
assumed compatible seating. No numerical Duad slowdown is imposed. These are
finite-model current witnesses, not a measured photon observation law. A single
outer reclosure can emit on several channels; channel ticks are not additional
parent closures.

`bip` follows the pinned Main definition: distinct reclosure after the initial
closure. Consequently the informative cross-field quantity is parent closures
per **reference** bip. Parent closures per its own new bips would be one by
definition. H1 displacement traversals, hinge events and partial returns remain
separate. The baseline has 124,064 traversals in four complete measured parent
returns and 3,507 in the incomplete next return. None of that partial return is
counted as a closure.

## What remains unresolved for decay

An admitted generic folded field is not yet the admitted physical Og-294
nucleus. The construction has no derived C22 nuclear arrangement, evolving
internal nuclear coupling/retention law, or daughter transformation witness.
Ordinary emitted current is not parent decay.

The declared nonnegative parent load over the baseline window is 224,657,122.
Oppositely signed lags are not cancelled before taking magnitudes. Its residual
would be `P − C_close`, and surplus `max(0, P − C_close)`. The existing sources
do not determine `C_close` for this constructed nucleus. With this same trace,
the unselected choices `C=P/2`, `C=P` and `C=P+1` give positive, zero and
negative residual respectively. See `review/capacity_obstruction.json`.
Even positive surplus needs an actual loss/retention and daughter rule before
it can become a decay event. No choice is selected to match an exposed lifetime.

Therefore `physical_isotope_closures_until_decay`, survival probability,
half-life, daughter identity and seconds remain null. Continuing the finite
trajectory to its horizon is not evidence that physical Og-294 survived that
interval. The next dependent scientific work is a source-supported nuclear
assembly and internal update, followed by the corresponding retention and
transformation witness. SI calibration can remain separate.

## Validation and reproduction

The 18 regression tests run in normal and optimized Python. They exercise actual
admission, alias/future-history rejection, exact input types, state consumption,
label invariance, prefix preservation, matched feedback, native directional RCD,
current seating, altered emission/contact provenance, independent reference
returns, window conservation and partial-return counting. A memoized immutable
trace accessor is checked against the original native accessor; replacing a
trace creates a fresh digest. The source admission module is unmodified.

Full normal/optimized replay evidence is in `review/replay_check.json`. All
four finite executions validate their outer waves, returned currents and
native P/R comparisons. The included input files are hash checked. This is a
detached application experiment: no manuscript, PR or remote branch was
modified; the full upstream CI suite and manuscript builds were not run.

Run from this directory with Python 3.11 or newer:

```sh
python3 -m unittest -v test_constructed_coupling
python3 -O -m unittest -v test_constructed_coupling
python3 constructed_coupling.py --out replay
python3 -O constructed_coupling.py --out replay_optimized
```
