# Matter I reference companion

Open `matter1-reference.html` directly in a browser. It is standalone and makes
no network requests. The default chart shows all 118 Z/symbol pairs and the
eight unfilled reference slots; narrow screens use a scrolling enclosure index
with the same visible identities and role marks.

The thick badge edge encodes a declared role: left Πα, bottom Hμ, right ΠΩ,
top boundary seat. The dotted outline marks an unfilled reference slot. The
line encodes seat order. These marks do not assert physical transitions,
retention, admission or isotope occurrence. Position 126 is a boundary seat
and remains unfilled in the present reference set.

Selected detail preserves reference A as a candidate input. The optional A
control evaluates `30Z + 68(A−Z) + 1 + 4s` as a conditional support sum. It is
not an observed isotope catalogue or a native RD admission. Its numeric upper
input bound is a UI bound, not an isotope boundary.

`matter1-layout.json`, the HTML data block, and the vector PDF/SVG in
`../figures/` are generated by `../scripts/generate_matter1_wheel.py` from the
authoritative `../data/m1/matter1_elements_1_118_ledger.csv`. Edit the template
and generator, then regenerate explicitly; do not hand-edit generated output.
The source hash is retained in the layout and figure manifest.

The static export is 180 × 205.568 mm with 9.3 pt minimum scientific text.
Final manuscript inclusion must preserve the explicit 180 mm width. The
generated PDF is the authoritative print deliverable; browser print reflow is
not claimed to meet that physical-size contract.

Verification commands, run from the repository root with the dependencies
installed in the chosen Python/Node runtimes:

```sh
python3 -m unittest discover -s manual2/tests -p 'test_matter1_*.py' -v
python3 manual2/scripts/check_matter1_figure.py
node manual2/scripts/check_matter1_companion.cjs
```

Generation requires matplotlib; PDF checks require pdfplumber. Browser checks
require Playwright and Chromium (`CHROMIUM_EXECUTABLE` may select an installed
binary). `--screenshots-dir /absolute/output/path` records optional browser
captures. Checkers leave source/data/figure/companion inputs unchanged and
print results; they do not regenerate or repair them.
