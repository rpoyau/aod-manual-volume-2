# Worked record template

Record class: select native exact fixture, declared model/simulation, metrology record or empirical comparison.

**Setup.** Bind source, scope, lineage, inputs, declared law and admissibility.

**Derivation.** Show the exact computation and its owning source anchors.

**Specialization.** State the particular fixture or model choices, if needed.

**Calibration.** For a calibrated record, identify measurand, protocol, observation map, reference realization, unit, uncertainty/dependence, resolution, repeatability and traceability. Omit for an uncalibrated exact fixture.

**Falsification.** State the specific negative control or criterion and actual result when executed.

**Provenance.** List precise internal source and data/implementation bindings.

**Literature note.** Give relevant external provenance without using it as an undeclared native premise.
